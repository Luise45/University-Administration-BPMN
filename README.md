## Project Overview
This BPMN was modelled to show the administrative process done by the university managment during each semester. 

## Main BPMN Process
The main process includes three pools, the teachers, the managment and the personel responsible for a module. 
<img width="3430" height="1480" alt="LehrbetriebVerwaltenErweitertSubprozess" src="https://github.com/user-attachments/assets/5bd7a0e6-cee6-43c6-a498-2db65a37bee5" />

The central task of the managment is to determine the required classes each semester, search for teachers and if there is a lack, hire new personel. 
<img width="9056" height="5677" alt="Screenshot 2026-05-30 at 19 35 28" src="https://github.com/user-attachments/assets/1c00396a-468e-407e-8866-b4cd8bf17b56" />

After the the first classes draft and the recruiting process, time tables and contracts are prepared and send. After the semester, the payment of personel is issuesd. 
<img width="1151" height="810" alt="Screenshot 2026-05-30 at 19 36 56" src="https://github.com/user-attachments/assets/3016d6aa-6100-4919-bc1d-19184752981e" />

The main process includes four important subprocesses: 

1. first draft of timetable 
2. addition of new personel
3. final draft of timetable
4. payment
